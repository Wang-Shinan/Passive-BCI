# EEG 视线方向分类

入口：`/#/smr-gaze`，首页与 SMR 个体化适配页均有链接。连接真实 EEG 并开流后，在本地开发服务中打开页面，填写被试编号，点击「全屏采集并训练」。无需眼动仪，也不要求运动想象。

每次先注视中央 2 秒，再直接望向出现的标靶并保持 3 秒。每组左右上下各 4 次，顺序按会话随机种子打乱；共 3 组、48 次，组间手动继续。标靶在左右 12%/88%、上下 16%/84% 的屏幕位置。头部保持不动，组间可眨眼休息。Esc、停止按钮、离开页面或切到后台会结束录制，未完成试次不会进入训练。

原始 EEG 和事件写入 `smr-gaze` 会话，方向标签为 `gaze_left/right/up/down`。它们代表实验指令，不是经过眼动仪验证的实际注视方向。此会话与 `smr-adapt` 运动想象数据分开，不会通过旧的 SMR 拟合命令加载。本页不启动或替换 REVE 模型。

分类器使用当前原始 EEG 环形缓冲区的全部通道（包括显示时隐藏的通道），不经过 SMR 的 mu 频段功率提取。每通道减去最近 1 秒中央基线的截尾均值，再提取标靶期 0.15–0.8、0.8–1.6、1.6–2.6 秒三个区间的截尾均值。各区间去除两端各 10% 样本，以降低孤立尖峰影响；这不等于完整的眨眼检测。解码对象是眼动引起的电位变化，保留其符号和时间信息。

使用等先验、对角协方差正则化 LDA。方差固定采用 20% 向全维平均方差收缩，并设置 1 uV² 下限。每试次只有一个特征向量，前两组训练、第三组留出评估，无窗口随机拆分。评估后使用全部有效试次拟合最终模型。剔除断流、计时中断、采样数明显不符及非法数值试次；通道或采样率改变时中止采集。

最终模型按被试编号保存在浏览器 localStorage，支持 JSON 导出。本轮事件、特征、混淆矩阵及模型参数也可导出。训练与验证必须使用相同通道顺序和采样率。「独立验证」使用已保存模型完成另外 16 次，不更新参数，也不向被试显示预测方向。

模型预测接口为 `predictGaze(model, gazeFeatures(baseline, target, sampleRate))`。当前是带中央基线的试次级四分类器，不是连续注视坐标估计器，不包含中央/无指令类别，也没有接到现有游戏控制流。换会话、换电极位置后的稳定性需用独立验证实测；训练完成不代表已证明跨会话鲁棒性。

时间戳来自浏览器阶段切换与 EEG sampleClock；浏览器显示刷新、设备传输可能存在延迟，原始 EEG 与阶段事件均保留供离线复核。
