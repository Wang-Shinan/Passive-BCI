# 视频观看与脑电反馈

入口：`/#/video`，已加入实验目录。页面复用 Passive-BCI 的特征面板、模型服务面板、SessionLogger 和 EEG 录制工具。

## 使用

1. 在采集页连接设备并开始采集；仅试播视频可以跳过此步。
2. 进入视频实验，添加多个本机视频或整个文件夹（含子目录）。每次导入追加到现有列表，不中断当前播放，也不清空类别映射。重复按相对路径（单文件选择时为文件名）、大小和修改时间判断，不进行内容哈希；单文件与文件夹方式混合导入可能保留两条不同路径的记录。文件通过浏览器对象 URL 读取，不上传。可从已挂载的 NAS 选择文件；刷新后需重新选择。
3. 选择被试，在本页点击录制工具的“开始本局”，再播放。EEG 特征在下方面板显示；只使用采集流，不自动生成演示特征。
4. 在模型服务面板选择任务和已有分类头，连接模型。把每个返回的类别映射到一段视频；未映射类别不切换。
5. 显式启用模型切换。默认阈值为 0.7、连续确认 3 次、冷却 5 秒，均可调整。这些是可用的初始控制参数，不是已验证的生理判别阈值。
6. 结束后暂停播放并点击“结束本局”，在会话库检查数据。未录制时仅有有限的内存日志缓存。

模型切换仅在视频播放、真实 EEG 新鲜、模型 ready 且源兼容时处理启用后的新预测。拒绝重复、乱序和超过 1.5 秒的预测。低信心或预测间隔过长会清空连续证据；同一持续类别不重复触发。暂停／缓冲期间不切换，保留切换冷却。模型版本／类别表改变时解除接管并清空映射。修改映射、门槛或手动选片也解除接管。

切到另一段从头播放；播放中切换保持播放，暂停中手动切换保持暂停。浏览器拒绝播放或无法解码时显示错误。可独立开启“播完顺序切换”；最后一段结束后停止。

## 交互界面

模型和分类头选择不再因录制而禁用。选择是待应用配置；点击启动应用时，共用模型服务先保存当前录制段，再切换模型，成功后按原被试、实验和设备配置开始新段。更换连接地址时同样处理；未录制时只切换模型，不自动开录。

保存失败不继续切换；模型或新录制启动失败时提示错误，保留已保存数据。切换过程仍串行执行。这里重新开始的是录制段，不自动重置影片进度或实验试次。另一标签页独立持有的录制缓冲需由该页面保存，不能在本页直接丢弃。

片单、特征监控、全部特征配置和模型连接设置可独立折叠。“专注观看”扩展播放器并收起侧栏，不改变模型接管状态。主曲线可选择特征、查看最近 15／30／60 个窗口，通过鼠标或键盘滑杆查看历史值，支持返回最新窗口和柔光开关。纵轴显示原始特征值并自适应范围。

未连接 EEG 时可显式开启“预览曲线光效”；模拟数据仅在绘图组件内使用，不进入录制、特征流或模型。真实特征到达后自动使用真实数据。

## 记录

- `video_playlist_append`：文件名、大小、修改时间与会话内 ID。
- `video_loaded`、`video_playing`、`video_pause`、`video_seeking`、`video_seeked`、`video_buffering`、`video_ended`、`video_error`：播放状态和媒体时间。
- `video_prediction`：播放时接收的预测与模型版本。
- `video_model_control`、`video_model_decision`：接管配置及分类决策。
- `video_switch`：前后视频、原视频时间、切换来源、预测及最近的特征快照；快照新鲜度以同期 EEG／特征状态判断。
- `video_features` 上下文：当前视频、媒体时间、EEG 特征值和特征时间。

SessionLogger 使用现有采样时钟附加 EEG 对齐信息，活跃录制时写入会话事件和上下文。这里的浏览器播放事件不等同于经过光电或硬件触发验证的刺激 onset；不保证显示器帧级同步。特征窗口可能跨越切片边界，分析时需按窗口时间处理。

## 与 visual-video-task 的关系

参考项目：[18yiba/visual-video-task](https://github.com/18yiba/visual-video-task)，检查的 master 提交为 `fdb6ba370ceb0acb866d7ebe99b306920347d358`。

该版本是 Python／PsychoPy 桌面程序，并非网页播放器。经确认，本次将“本机材料列表、视频播放和 EEG 事件关联”适配为现有 React 工作区内的新实现，没有复制其 Python 源码，也不要求安装 PsychoPy。

这不是原研究协议的等价迁移：固定 Session、材料 SHA256 校验、题库、情绪评分、断点续跑、串口触发和面部录像尚未接入。视频素材本身不在本仓库内；文件名／大小不是内容哈希。浏览器支持的编解码器也与 PsychoPy 不同。

## 验证

`control.test.ts` 验证连续判定、重复／过期／乱序过滤、低置信度重置及跨播放中断的冷却。浏览器使用本地生成的两段 MP4 检查导入、实际解码播放和手动切换续播。真实 EEG、实际分类头和端到端录制效果仍需连接设备后验收。
