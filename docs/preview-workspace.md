# 实验目录预览

## 当前范围

根据 2026-09-22 的预览反馈，撤销第一版虚构工作空间、账号式装饰、营销文案、重复示意图、模拟训练与模拟实验弹窗。

本版重做实验目录，并为目录和独立页面提供共用的亮色/深色模式。所有入口使用 `src/App.tsx` 的原有路由，直接渲染真实独立页面，页面内容、控制器和协议没有被预览组件替换。实验页原有的“返回首页”会返回新目录。

- `src/preview/Preview.tsx`：目录与搜索。
- `src/preview/data.ts`：指向原路由的入口名称、用途、运行条件。
- `src/preview/preview.css`：目录布局与配色。
- `src/preview/Theme.tsx`、`theme-context.ts`、`theme.css`：共用主题状态、实验页切换栏与预览样式。
- `src/App.tsx`：增加可选首页、页面顶栏与自动启动模型参数；原应用的默认行为不变。
- `vite.preview.config.ts`：复用应用配置及 API 插件，使用 5174 端口。

## 共用配色

默认使用橙白亮色模式，参考 Anthropic 官网的暖白底色与克制的边框。目录与独立页面右上角的“亮色 / 深色”共用同一个选择，浏览器使用 `passive-bci.preview.directory-theme` 保存选择，刷新或从实验页返回目录后恢复；主题存储不可用时仍可在当前页面切换。

预览入口通过 `html[data-preview-theme]` 设置主题；原版入口不挂载主题提供器，也不加载主题 CSS。页面底色、面板、输入框、按钮、日志、图表坐标与提示框同步配色。舒尔特数字区域支持浅色；按后续反馈，N-back 字母与注视点区域固定使用深色背景和浅色文字。SMR/眼动靶标区、方块棋盘、图任务画布以及全屏闪卡保留任务配色；固定深色区域显式保留浅色文字，避免继承亮色主题后失去对比度。独立实验页增加一个普通文档流中的切换栏，不覆盖实验画面；实验时序、数据记录与输入事件不变。

## 行为与数据

目录不填充模拟波形、运行模型、最近会话或训练指标。侧栏 EEG 状态直接读取现有 LiveEegBadge。

这是实际应用页面的预览入口。点击实际页面中的开始、录制、训练、下载或删除，会执行原有业务逻辑。预览入口关闭 SMR 上下控制、SMR 个体化适配、方块 SMR 适配三个页面原有的自动模型启动；需要模型时在采集页手动启动。仅浏览目录和切页不自动启动设备、模型或训练。真实设备与配套模型依赖仍需按原项目配置。

“眼动版俄罗斯方块（旧 LDA）”指已有 `/gaze-tetris` 页面：从 EEG 提取眼动方向特征，使用浏览器中保存的本被试旧 LDA 模型，无需运动想象，也不使用摄像头。该入口标为旧版，不暗示当前采集页面仍会生成这个旧模型。

## 方块布局与图标（后续反馈）

俄罗斯方块采用左右对称栏：左侧是状态、调速、教师与 SMR 控制，棋盘居中，右侧是压力输入和 EEG 特征。两侧可独立收起，也可用“专注棋盘”同时收起；用隐藏容器保留控制组件与参数。暂停/继续和重开始终留在棋盘上方。大屏两侧可各自滚动，窄屏棋盘先显示、控制区排在下方。棋盘仍可拖动调整大小，棋盘按所选尺寸显示，宽高均不受视口限制，超出屏幕时使用页面横向与纵向滚动。最大单格从 52px 提高到 96px，顶部增加尺寸滑条和宽高显示，放大后无需滚到棋盘底部再缩小；收起两侧可获得更大的可用宽度。

方块压力驱动默认 `cognitive_load`，使用独立的 `passive-bci.tetris-stress-driver` 保存后续手动选择。移除 `useStressControl` 将 cognitive_load 强制改回 rms 的旧逻辑；其他实验的默认驱动仍是 rms，已有明确选择继续保留。特征计算、映射和实验协议不变。

目录、主题切换与常用控制增加带文字标签的线条图标，图标本身对辅助技术隐藏。N-back 任务区、光标任务区和方块棋盘保留深色。

验证：197 项现有测试通过；浏览器确认棋盘居中、两侧独立折叠、专注模式、折叠不卸载控制组件、压力特征选择刷新后保留、N-back 两种主题下保持深色。390/768/1024/1100/1292/1644px 无页面横向溢出。未连接硬件或执行录制/训练。

两侧面板恢复独立拖拽调宽：拖动左栏右边缘、右栏左边缘；分隔条支持左右方向键与双击复位。栏宽分别持久化，窄屏自动改用上下布局。栏宽和棋盘尺寸独立保存；调整面板、折叠或缩小浏览器窗口都不压缩棋盘，超出的内容允许滚动。

## SMR 合并与 N-back 全屏（最终增量）

目录中的“SMR 个体化适配”和“全屏 SMR 采集”合并为 `/smr` 页面，顶部切换普通 SMR / 全屏 SMR；两个模式共用被试编号，保留各自的模型任务、标签与录制类型。旧 `/smr-adapt` 和 `/smr-gaze` 地址分别转到对应模式。实验进行、保存录制、训练或模型操作期间禁用模式切换。合并后目录共 18 个入口。

“眼动辅助 SMR”的展示名称统一调整为“全屏 SMR”；内部 `gaze_smr` 标识和实验协议不变。

N-back 点击“开始一轮”后请求浏览器原生全屏，全屏成功后才开始呈现刺激和计时。全屏失败时不开始新一轮；退出全屏会中止并保存已完成试次，完成或主动中止后自动退出全屏。全屏画面和按钮保持深色，并支持空格及点击作答。

浏览器检查覆盖模式切换、共用被试编号、旧路由、运行时锁定，以及 N-back 全屏进入、作答、退出中止、完成退出和全屏请求失败。N-back 验证中的行为保存请求使用拦截响应，未生成真实录制。
